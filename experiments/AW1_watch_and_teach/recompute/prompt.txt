Please run code on this file only and report to 4 decimals. (1) For each arm, making per adult-year = (sum over seeds of makes) / (sum over seeds of adult-years). (5) For each arm, the pooled skill = sum of wb_craft_sum / sum of wb_adults, and for t the difference from v with the same paired bootstrap interval. Report only your computed numbers.
