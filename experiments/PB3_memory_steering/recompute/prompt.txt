Blind recompute for a study in an agent-based simulation (ACL study PB3: when people choose using a memory of their own past weeks instead of a habit table, do they finish more of what they start, and is that because the memory predicts better or only because the habit table looks one week ahead?). Please compute only from the attached file pb3_counts.csv; you have not seen and should not guess any earlier result. Arms: c = baseline (habit table with a one-week look-ahead), c0 = baseline with the look-ahead removed, P = choices steered by the memory, Pp = memory with a two-week return, x = sham; the same 32 seeds (23301-23332) in every arm. Columns per world: m3_g_chains and m3_g_made (gather chains: a person gathered a material they needed for a recipe they value; made = they made such a recipe within 8 weeks), m3_m_chains and m3_m_made (opportunity-matched chains), living_weeks, extinct (1 if everyone died). Compute: (1) for each arm, M3 = sum m3_g_made / sum m3_g_chains - sum m3_m_made / sum m3_m_chains; (2) the differences P - c0, P - c and c0 - c in M3, each with a 95% interval by a paired world bootstrap: 10,000 times draw 32 seeds with replacement, use the same drawn seeds (with multiplicities) for every arm, recompute M3 from the pooled sums, take the 2.5 and 97.5 percentiles of each difference; (3) the guards for c0, P and Pp each against c: the living-weeks ratio sum(arm) / sum(c) with a 95% interval by the same bootstrap (raised if the ratio is below 0.90 and its upper bound below 1), and the number of extinct worlds minus c's (raised if 3 or more); (4) the primary reading: 'better prediction' if the P - c0 interval lies wholly above 0 and its point is at least +0.005; 'myopia, not prediction' if the P - c0 interval does not lie wholly above 0 while the c0 - c interval lies wholly above 0; otherwise 'unclear' (and not a success if a guard is raised for P); (5) the co-primary reading: 'replicates' if the P - c interval lies wholly above 0 and the P / c living-weeks interval lies wholly above 1. Report M3 per arm (4 decimals), the three differences with intervals, the guards, the P / c living-weeks ratio with its interval, and both readings. Run code if you can, loading the attached file with your code tool.
