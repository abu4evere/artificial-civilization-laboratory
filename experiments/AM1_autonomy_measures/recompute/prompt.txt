Blind recompute for a read-only study in an agent-based simulation (ACL study AM1, which checks whether candidate measures of goal-directed behaviour fall in deliberately constrained control worlds). Please compute only from the attached file am1_counts.csv; you have not seen and should not guess any earlier result. Arms: c = baseline (v11), h = no learned habits, a = fewer acts (cannot make), t = more chance in choices, x = sham; the same 32 seeds (22501-22532) in every arm. Columns per world: m3_g_chains and m3_g_made (gather chains: a person gathered a material they needed for a recipe they value; made = they made such a recipe within 8 weeks), m3_m_chains and m3_m_made (opportunity-matched chains: the material lay where the person stood but they did not gather it), the same four for m5 (only chains whose next decision was a food action), living_weeks, extinct. Compute: (1) for each arm, M3 = sum m3_g_made / sum m3_g_chains - sum m3_m_made / sum m3_m_chains, and M5 the same with the m5 columns; (2) the differences c - h and c - t for M3 and for M5, with 95% intervals by a paired world bootstrap: 10,000 times draw 32 seeds with replacement, use the same drawn seeds (with multiplicities) for every arm, recompute each measure from the pooled sums, take the 2.5 and 97.5 percentiles of each difference; (3) the reading per measure: 'validated' if both c - h and c - t intervals lie wholly above 0, 'partly validated' (name which control) if only one does, otherwise 'not validated'; (4) the sanity count: the total of m3_g_made + m3_m_made in arm a (it must be 0); (5) the sum of living_weeks per arm. Report M3 and M5 per arm (4 decimals), the four differences with intervals, the readings, the sanity count and the living weeks. Run code if you can, loading the attached file with your code tool.
