Blind recompute for a read-only study in an agent-based simulation of hunter-gatherers (ACL study PB0: would knowing the outcome of each option change a person's choice?). Please compute only from the attached file pb0_outcomes.csv; you have not seen and should not guess any earlier result. Each row is one option of one sampled decision (seed = world, decision = decision number within the world, option = option index); score = the person's own score for that option; is_top = 1 for the option with the highest score (exactly one per decision); r1..r4 = the person's outcome over 4 weeks when that option was taken, in four replays (replay i uses the same random seed for every option of a decision). Compute: (1) for each decision whose top option is present, the winner = the option with the highest mean of r1 and r2 (ties: the higher score, then the lower option index); the gain = mean(r3, r4) of the winner minus mean(r3, r4) of the top option (0 if the winner is the top option); (2) G = the mean gain over all decisions (pooled), and A = the mean over decisions of the absolute value of the top option's mean(r3, r4); (3) a 95% interval for G by a world bootstrap: 10,000 times draw the worlds (seeds) with replacement, recompute G as (sum of gains over the drawn worlds' decisions, with multiplicities) / (number of those decisions), take the 2.5 and 97.5 percentiles; (4) the reading: 'GO' if the interval lies wholly above 0 and G >= 0.05 x A, otherwise 'NO-GO'; (5) the number of decisions, and the share where the winner is not the top option. Report G with its interval (4 decimals), A, G/A, the reading, the number of decisions and that share. Run code if you can, loading the attached file with your code tool.
