# TG1 — Things on the ground: if a tool can lie somewhere and anyone can pick it up, what happens? (DRAFT for the creator; nothing built or run)

**Why.** Three of the creator's new possibilities need the same missing piece. ACL has no way for a made thing to lie
on the ground and be picked up by someone else:
- **bodies (v4):** a dead person's tools can only be taken by a partner or child who stands there;
- **digging (DG1):** a pit can hide food, but not tools;
- **water (WA1, draft):** a floating thing that drifts ashore could never be found.

In v4, a made thing is only ever in someone's hands (or inherited); when a person carries too many, the oldest is
simply gone. This is physics, not culture: a dropped thing lies where it fell.

## The candidate (one setting, `things_lie`, default 0 = nature v4 exactly)

1. **Things fall where they are left:** a thing a person can no longer carry (over v4's item limit) is set down on the
   tile instead of vanishing; the tools of a body lie with it (kin still take theirs first).
2. **Things on the ground wear** with weather (as v4 wears things in use), and are gone when worn out.
3. **Anyone can pick one up** with v4's existing action "take" (offered when a thing is in reach), by the same
   reasons that move people to take food that is not theirs: they value that kind of thing and have room. Taking a
   thing whose owner is alive and nearby is seen as taking (v4's consequences).
4. **What lies on the ground can be seen**, so a thing others have dropped can be watched, copied and learned from,
   as v4 already lets people learn from things others hold.

## Questions for the creator and GPT

- Does picking up through "take" (no new action) script anything? It shares the learned value of taking food.
- Should a thing lying near its living owner still be theirs (taking = stealing), or does ownership end when it is put
  down?
- Order: TG1 before water (WA1). Realistic rot for bodies (BD2) can run at any time.
