Blind recompute for a study in an agent-based simulation (ACL study BN1). Please compute only from the attached file bn1_cells.csv; you have not seen and should not guess any earlier result. Columns: arm, seed, cell, n, sum_abs. Each row is one world (seed) and one cell (a situation|action pair): n = number of early-life habit updates in that cell, sum_abs = the sum of |q - G| over them (q = the learned value, G = the realized return). Arms c (the baseline), z, x and s (a sham) each have the same 32 seeds (21801-21832); arm r has 8 reference worlds (21901-21908) used only for weights. A cell missing for a world means n = 0 there. Compute: (1) fixed weights: w_cell = (n pooled over the 8 r worlds) / (total n in r); (2) common cells: w_cell > 0 and n pooled over the 32 seeds is at least 30 in every one of c, z, x and s; (3) coverage per arm (c, z, x, s) = the share of that arm's total n that lies in common cells; (4) per arm, E = sum over common cells of w_cell * (pooled sum_abs / pooled n), divided by the sum of w_cell over common cells (pool over the 32 seeds within each cell); (5) D_z = E_z - E_c, and the sham difference E_s - E_c, also E_x - E_c and E_x - E_z; (6) 95% intervals for these differences by a paired world bootstrap: 10,000 times, draw 32 seeds with replacement and use the same drawn seeds (with their multiplicities) for all four arms, keep the weights fixed, and in each replicate leave out (for all arms) any common cell whose resampled n is 0 in any arm, renormalizing the weights; take the 2.5 and 97.5 percentiles of each difference; (7) apply this frozen rule: 'inconclusive (coverage)' if any arm's coverage is below 0.80; else 'inconclusive (sham)' if the sham's point difference E_s - E_c lies outside +-0.01; else on D_z's interval: 'z better' if its upper bound < -0.02; 'z not worse' if its upper bound < +0.02; 'z worse' if its lower bound > +0.02; otherwise 'inconclusive'. Report: the number of common cells, coverage per arm, E per arm (4 decimals), the four differences with intervals, and the reading. Run code if you can.
