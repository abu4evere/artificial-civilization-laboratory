Blind recompute for a study in an agent-based simulation (ACL study FX1, a check that three code fixes do no harm). Please compute only from the attached file fx1_counts.csv; you have not seen and should not guess any earlier result. Columns: arm (c = baseline v11; f = all three fixes; f1 = fix 1 only; f23 = fixes 2 and 3 only; x = sham), seed, living_weeks (person-weeks lived in years 100-200), extinct (1 or 0), kinds (new kinds invented in a window), remade (how many of them were made again within five years); the same 32 seeds (22401-22432) in every arm. Compute: (1) for each of f, f1, f23 and x, the population ratio = sum of living_weeks of the arm / sum of living_weeks of c, with a 95% interval by a paired world bootstrap: 10,000 times draw 32 seeds with replacement, use the same drawn seeds (with multiplicities) for every arm, recompute each ratio from the pooled sums, take the 2.5 and 97.5 percentiles; (2) the number of extinct worlds per arm; (3) the frozen reading for f: 'harm: investigate' if the population ratio f / c is below 0.90 and its upper bound is below 1, or if f has 3 or more extinct worlds more than c; otherwise 'no harm'; (4) R per arm = sum of remade / sum of kinds. Report each ratio with its interval (4 decimals), the extinct counts, the reading and R per arm (4 decimals). Run code if you can, loading the attached file with your code tool.
