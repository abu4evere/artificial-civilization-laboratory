Blind recompute for a fault-fix harm check in an agent-based simulation of hunter-gatherers (ACL study FF2). Please compute only from the attached file ff2_counts.csv; you have not seen and should not guess any earlier result. Arms: c = the current world (v12), f = all three fixes, f8, f4, f5 = one fix each, x = sham (an extra random draw); the same 32 seeds (22701-22732) in every arm. Columns per world: living_weeks and adult_weeks (years 100-200), adult_hunter_weeks (adult hunters in hunts), hunts, hunt_successes, extinct (1 = the world died out). Compute: (1) the ratio R = sum living_weeks in f / sum living_weeks in c, with a 95% interval by a paired world bootstrap: 10,000 times draw 32 seeds with replacement, use the same drawn seeds (with multiplicities) in both arms, recompute R from the pooled sums, take the 2.5 and 97.5 percentiles; (2) the number of extinct worlds in each arm, and f minus c; (3) the reading: 'harm: investigate' if R is below 0.90 with its upper bound below 1, or if f has 3 or more extinct worlds beyond c's; otherwise 'no harm'; (4) for every arm, adult hunter-weeks per 1,000 adult-weeks (pooled sums), and the ratio of f's value to c's with a paired bootstrap 95% interval as in (1). Report R and its interval (4 decimals), the extinct counts, the reading, and the hunter-week figures. Run code if you can, loading the attached file with your code tool.
