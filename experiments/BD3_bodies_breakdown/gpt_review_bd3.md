# GPT's review of the BD3 draft (24 October 2026)

**Source: GPT (ChatGPT, the creator's account, main ACL chat), asked by the assistant. GPT's opinion, in summary; not
verified sources and not sign-off.**

Verdict: worth doing; revise narrowly, then freeze. Do not grow it into a full factorial; do not redirect it toward Bob
(it is an agreed v6 obligation).

1. **Leave-one-out is right as primary**, but it answers "what changes when part j is removed with the rest on", not
   "how much of the gain part j causes alone"; parts that depend on each other can each show a large removal effect.
   Add-one arms would have to be F−all + one part (N has no body to put a part into); not needed now.
2. **`no_eat` is not clean as drafted**: meat and carried food share one store entry, so blocking the store blocks
   both. Tag food by source (meat vs carried) and block only meat; test mixed stores, partial takes, rotten meat, kin
   reclaiming, and conservation of food. Check whether an untakeable store still draws people to it.
3. **±2% is a sensible relevance margin**, but reword the readings: above +2% = meaningful; above 0 but overlapping
   +2% = positive, size uncertain; below 0 = works against; **inside ±2% = small**; anything else = inconclusive
   ("not shown" must not read as "no effect"). 1,024 seeds: worth it (about ±3.9% for F/N if variance is like BD2's),
   but may not resolve parts of 1–2%; freeze the size, no extension. **Holm correction (or simultaneous intervals)
   across the five parts.** Bootstrap the eight arms together by seed. Extinction: paired risk difference,
   discordant pairs, exact McNemar.
4. **Missed:** body-store occupancy, kin movement toward bodies, where `no_carried` puts food, rot-sickness against
   meat's calories, and interactions. **F−all against N is not "bones"** unless shown to be the only difference left;
   a residual would itself be a finding. Optional ninth arm **F−eat−carried** for the eat × carried interaction.
5. **Avoidance needs a direct measure:** foul exposures and penalties actually applied; return rate to a fouled place
   when reachable; how often it is chosen among options; how long the difference lasts; by weeks since death (0–4,
   5–14, 15–52, 53–104). Movement is the mechanism, not a confounder: do not adjust it out of the primary.
6. **Ways it could be wasted:** switches that do not isolate their part; manipulation checks that show absence but
   not opportunity (show the part would have happened); BD3 with switches at 0 not identical to v6 (check full
   state and RNG); a null read as failure (it would show the parts work together or something else is going on).
