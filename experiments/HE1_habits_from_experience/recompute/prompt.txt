Compute, each with a 95% interval by a paired world bootstrap (10,000 times draw 32 seeds with replacement, use the same drawn seeds with multiplicities for every arm, recompute from pooled sums, take the 2.5 and 97.5 percentiles): (1) the harm guards for h against c: the living-weeks ratio sum(h) / sum(c) (raised if below 0.90 with its upper bound below 1); extra extinct worlds (raised if 3 or more); starvation deaths per 1,000 living-years (living-years = living_weeks / 52) and the ratio h / c (raised if above 1.25 with its lower bound above 1); adults' mean health = sum census_health / sum census_adults, and the difference h - c (raised if below -5 with its upper bound below 0); (2) the co-primary: M3 = sum m3_g_made / sum m3_g_chains - sum m3_m_made / sum m3_m_chains for c and h and the difference h - c (passes if its interval lies wholly above 0); makes per adult-year = sum makes x 52 / sum adult_weeks_win for c and h and the ratio h / c (passes if its lower bound is above 1); (3) the reading: 'supported' only if no guard is raised and both co-primary parts pass. Report every value above with its interval and the reading. Run code if you can, loading the attached file with your code tool.
