# L1 — post-pilot methodological check (written before it was run)

The original pilot stop rule was triggered: two of four pilot worlds (702, 704) died out under L1. Because the pilot
lacked same-seed controls, a follow-up survival-only diagnostic was run, at the creator's decision, to determine whether
extinction reflected L1 or seed fragility.

**The diagnostic:** the unchanged world (arm C) on the same pilot seeds 701–704, 120 years. It reads only population
every ten years and whether the world died out, exactly as the pilot did. It uses none of the experiment's seeds
(601–616) and reads no outcome measure.

**Readings, written before it was run (the creator's):**
- **If the same seeds also die out without L1:** the pilot did not show that L1 is too harsh; it showed that the pilot
  seeds include fragile worlds. The next step is a redesigned pilot with same-seed controls, frozen before it runs, not
  abandoning L1.
- **If they survive without L1:** that is much stronger evidence that removing winter growth materially harms survival.
  L1 then becomes interesting even if delayed return never emerges: winter growth would be shown to be an important
  stabiliser of ACL's world.

The frozen pre-registration (`preregistration.md`) is unchanged. The main experiment does not run on the strength of
this diagnostic alone; any next step returns to the creator.
