Blind recompute for a read-only study in an agent-based simulation of hunter-gatherers (ACL study PB1: can a small linear predictor, learning from one person's life, predict the effects of that person's actions better than a simple table of past averages, in situations the person has never met?). Please compute only from the attached file pb1_sums.csv; you have not seen and should not guess any earlier result. One row per world (32 worlds). Columns: sse_L_pair and sse_B_pair = summed squared standardised prediction errors of the linear predictor L and of the table baseline B on the primary cases (weeks whose situation-and-action pair the person had never lived before); n_pair = the number of those cases; the same three for the secondary cases (_prop: unfamiliar property combinations). Compute: (1) the skill of L on the primary cases = 1 - (sum over worlds of sse_L_pair) / (sum over worlds of sse_B_pair); (2) its 95% interval by a world bootstrap: 10,000 times draw 32 worlds with replacement, recompute the skill from the pooled sums with multiplicities, take the 2.5 and 97.5 percentiles; (3) the reading: 'the predictor learns and generalises' if the interval lies wholly above 0, otherwise 'it does not'; (4) the same skill and interval for the secondary cases; (5) the total number of primary and secondary cases. Report the skills with their intervals (4 decimals), the reading and the counts. Run code if you can, loading the attached file with your code tool.
