# GPT's review of the M1 draft (25 October 2026, sleep mode)

**Source: GPT (ChatGPT, the creator's account, main ACL chat), asked by the assistant while the creator slept. GPT's
opinion, in summary; not sign-off. "Freeze only with the creator's approval."**

- Strong and worth running; respects the mission (observe 1,000 years without giving knowledge or changing nature).
- Holding a good tool is not using it well: separate possession, knowledge and performance. Add **A4, functional
  performance** from existing records (e.g. E8.2's food per foraging attempt, with tool use, against comparable
  resources); A3 and A4 together are stronger evidence than A1 alone. No new physical tests, no nature change for it.
- Zero baselines: use differences or presence/absence, not ratios, and never add constants. Censoring: retention 25
  years after an inventor's death counts only deaths followed by 25 years of observation. Define traditions before data
  (repeated use, shown social transmission, persistence across cohorts).
- Name one primary outcome or a small co-primary set to prevent picking whichever metric looks good.
- ±10% is fine as a practical band; an interval wholly in 1.00–1.10 is "increase, below the meaningful margin"; report
  absolute changes too; "not significant" is not "flat".
- Add **D80** (80 founders on 40 × 40) as a secondary, descriptive arm if affordable: LP vs D80 (same founders,
  different space) and D80 vs C20 (same land, different founders). LP's low density may itself limit transmission, so a
  negative LP result would not show v6 cannot do it.
- Cohort test: two views, actual history (no adjustment) and context-standardized description (population, contacts,
  food, teaching chances), never read causally; the world stays the unit; different cohorts, not the same people.
- Test observers and reload over long-lived worlds too (memory and logging over 1,000 years).
