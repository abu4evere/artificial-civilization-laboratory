Blind recompute for a read-only study in an agent-based simulation of hunter-gatherers (ACL study PB1b: does an episodic-memory predictor, learning from one person's life, predict the effects of that person's actions better than a table of their past averages on situations they never met, and no worse on familiar ones?). Please compute only from the attached file pb1b_sums.csv; you have not seen and should not guess any earlier result. One row per world (32 worlds). Columns: sse_V_C = summed squared standardised prediction error of predictor V (B = the table, the baseline; E = episodic memory of own weeks; Eo = episodic memory of own and observed weeks) on case set C (u_pair = unfamiliar situation-action pairs; fam = familiar ones); n_u_pair and n_fam = case counts. Skill of V on C = 1 - (sum over worlds of sse_V_C) / (sum over worlds of sse_B_C). Compute: (1) the skill of E on u_pair and on fam, and of Eo on u_pair and on fam; (2) a 95% interval for each by a world bootstrap: 10,000 times draw 32 worlds with replacement, recompute each skill from the pooled sums with multiplicities, take the 2.5 and 97.5 percentiles; (3) the reading for E: 'GO' if E's u_pair interval lies wholly above 0 and E's fam interval's lower end is at least -0.02, otherwise 'not GO'; the same check for Eo; (4) the difference in skill Eo minus E on u_pair, with its bootstrap interval; (5) the total case counts. Report the four skills with intervals (4 decimals), both readings, the difference and the counts. Run code if you can, loading the attached file with your code tool.
