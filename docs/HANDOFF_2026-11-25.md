## Getting cloud access from another computer
The SSH key `~/.ssh/mindlab_cloud` stays on the laptop (a private key never goes to GitHub). On a new computer:
1. `ssh-keygen -t ed25519 -f ~/.ssh/mindlab_cloud` (no passphrase prompt needed for automation; the creator decides).
2. Add the new **public** key (`~/.ssh/mindlab_cloud.pub`) to each VM: Google Cloud Console -> Compute Engine -> VM ->
   **SSH** button (browser shell), then append it to `~/.ssh/authorized_keys` of user `mindlab-cloud`; Oracle Cloud
   Console -> **Cloud Shell** or the instance's console connection, user `ubuntu`. (The creator does the console part.)
3. Hosts: Oracle `ubuntu@129.80.176.86` (main machine: 16 threads, cheaper); Google `mindlab-cloud@35.221.60.73`.
College Wi-Fi blocks SSH (port 22): use home Wi-Fi or a phone hotspot.
