## The question (sent as one paragraph)
Council round 83 (ACL, 10 November 2026). ACL is an agent-based hunter-gatherer simulation; its people now get a neural-network brain (the creator's decision). The first test, NB1 (finished, recomputed blind by GPT and Gemini): each candidate option keeps its hand-written instinct score multiplied by an inherited gene g (start 1, range 0-2), and a small network (about 700 weights, 16 hidden units) adds its own score from raw features; children inherit one parent's network genome with mutation; within life the network learns by REINFORCE with one running baseline per person on the weekly feeling r = reward + 2 x mood change, with the gradient scaled by 1/temperature (temperature 0.2). Results over 600 years, 16 worlds per arm: the neural people are viable (3 of 16 worlds extinct vs 1 for the old minds; population 1.17x), but the reading is 'decorative': g ROSE from 1.00 to 1.23 (evolution leaned more on the hand-written rules); in a common garden, learning on lowered children's survival to 16 by 0.045 [0.024, 0.065] against learning off; generation 18 genomes were no better than generation 1; the learning network's scores correlated -0.30 with the instinct scores; starvation was 2.2x and child deaths 1.9x the old minds'. Our audit of the code found the world's deciding is still built for the old brain: (1) for each action the old brain pre-chooses ONE target by its own formula (best forage tile, best prey, one recipe, one destination), so the network only picks the verb; (2) physically possible actions are hidden behind old-brain thresholds (give food only with food > 2x own need + dependents' need + 1; take others' stash only if hunger > 0.4; steal only if hunger > 0.3; attack only if grudge > 0.15; care only with kin or affection > 0.3; children never explore); (3) the network is blind to the facts the instinct score uses (food on a tile, prey, water, fire, own stash, others' hunger, trust, grudge, strength, item values, memories, what others told it); (4) learning from others (children copying their carer; watching a better forager) writes only the old habit table, so for neural people it is dead; (5) the learning rule punishes needed hard work done in bad weeks (no state value, one-week horizon, step x5). Proposed NB2, in a copy of the frozen world with a sham arm, physics and feelings unchanged: options = what the body can do (several candidate targets per action, each with raw facts; old thresholds removed; real limits kept: energy, adulthood for courting, no kin as mates); the network sees the raw facts; actor-critic learning (a learned state value as baseline, a discounted multi-week return, no 1/temperature factor); social learning into the network (a child's network is nudged toward its carer's action in the same situation; seeing someone do well nudges toward their action); the instinct score stays only as an inborn bias weighted by the evolving gene g. Please answer briefly and concretely: (a) is the diagnosis right, and what did we miss? (b) which of the five fixes matter most, and should they be tested together as one package or separately (with what arms)? (c) how should candidate targets be offered so the option list does not explode (k nearest tiles? a fixed k per action?), and what raw features per option? (d) the actor-critic and social-learning rules: concrete form and numbers (discount, critic size, imitation strength), chosen before any data; (e) should the instinct score fade out entirely (g allowed to 0) or stay as a newborn prior; (f) the primary outcome and the reading that would show the network does the work (for example g falling while survival holds, plus a common garden); (g) your probability (0-100%) that NB2 as described yields 'the network does the work' within 600 years, and the single biggest risk.
