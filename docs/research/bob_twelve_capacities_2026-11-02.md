# Bob's twelve capacities, read against nature v11 (2 November 2026)

**What this is.** The creator sent (Telegram, 2 November 2026, 02:21) a list of twelve capacities that "may create
Bob". This note places each one against what ACL's nature v11 already has, using only `docs/ODD_v11.md` (written
2 November from `acl/`), `docs/research/measuring_autonomy_2026-11-02.md` and finished studies (KL1, UV1). It is the
assistant's reading, not a finding and not a proposal for a nature change. GPT and Gemini have **not** been asked yet.

**Labels.** *Given* = written into nature as a law. *Learned* = changes with each person's experience. *Missing* =
nothing in ODD v11 does it. *Not checked* = not looked up in the code for this note.

| # | capacity | in v11 | source |
|---|---|---|---|
| 1 | Perception | **Given, coarse.** People sense others within reach (12 nearest), food, water and animals in sight, marks, hearsay. Choices are made over 32 fixed situations: the world is sorted for them, not by them. | ODD §Sensing; habit table 32 × 19 |

## The assistant's reading
- The list is a good **scorecard**. It also matches the gap the autonomy note found: 5, 6, 7 and 8 are where ACL is
  emptiest, and they are the ones closest to Bob.
- **Risk:** building all twelve in directly would be *writing* Bob, against "minimum laws" (CLAUDE.md, the mission).
  Several (1, 9, 11) are already given as laws; the question for each is whether it must be given, or can grow from
  fewer laws.
- **Suggested use:** a measure for each of the twelve, read-only, run on every study's worlds, so progress toward Bob
  is tracked the same way each time. Planning or goals would come in only as a frozen nature-change test, one at a
  time, never tuned.
