## Browser practice learned today (Claude in Chrome)
- **Only the front tab works fully.** Background tabs freeze (screenshots time out, sends do not go through). Do the
  sending in a freshly created tab, or navigate the front tab to each chat in turn.
- **The creator uses the main GPT chat themselves.** Do not type into it while they are using it. Use a fresh GPT chat
  with one line of ACL context for council questions.
- **ChatGPT's new-chat box can hold an old draft.** Clear it (`selectAll` + `delete`) before inserting, and check that
  the text equals the question before clicking send.
- **Gemini sometimes runs out of code execution in a chat** ("capabilities are currently exhausted"). A new chat with
  the same file and prompt works. In Gemini, click send with a real click (`find` "Send message", then `left_click`),
  not a JavaScript click.
- **DeepSeek:** set the textarea with the native setter, then press Return in the front tab.
